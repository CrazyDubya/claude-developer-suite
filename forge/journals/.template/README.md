# Your Forge Journal

This is your personal learning and project journal for Claude App Forge.

## Getting Started

1. Copy this template to create your journal:
   ```bash
   cp -r journals/.template journals/your-name
   ```

2. Edit `progress.yaml` to set your learning goals

3. As you complete curriculum nodes, update your progress

4. Document your blueprint instantiations in `projects/`

5. Keep notes on insights and learnings in `notes/`

## Journal Structure

```
your-name/
├── README.md           # This file (customize it!)
├── progress.yaml       # Your curriculum progress
├── notes/              # Personal learning notes
├── projects/           # Your blueprint instantiations
└── decisions/          # Decision logs from blueprints
```

## Using with Claude Code

Claude Code can read your journal to:
- Understand where you are in the curriculum
- Recommend next learning steps
- Resume context from previous sessions
- Track your projects and decisions

Try asking:
- "What should I learn next?"
- "Where was I in the curriculum?"
- "Show me my project history"
